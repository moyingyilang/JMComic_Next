# 用户要求总表

本文件把用户在开发过程中**全部明确要求**归并成一份清单，逐条标注落实情况。
它是 2.0.0 发布前的核对表：任何一条未做到，都必须在发布说明里写明，不许含糊。

状态取值：**已完成并验证** / **已完成待验证** / **进行中** / **未做** / **待用户确认**。
